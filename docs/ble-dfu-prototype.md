# BLE DFU 試作

既存のXIAO nRF52840ブートローダーに、ZMKからBLE DFUモードへの再起動を要求します。
初回のみ、このブランチの左右のファームウェアを従来のUSBシリアルDFUで書き込みます。
ブートローダーやSoftDeviceを書き換える必要はありません。

## まず広告を確認する

1. 左右を起動して、通常どおり入力できることを確認します。
2. iPhoneのBLEスキャナーを開き、右側を先に試します。
3. Z・X・C・Vを同時押ししたまま、右のEnter位置を押します。
   左側を試すときは、同じFUNCTIONレイヤーで左Shift位置を押します。
   一度に片側だけ操作してください。
4. ブートローダーの広告（標準Adafruit実装では `AdaDFU`）やLegacy DFUサービス
   `00001530-1212-EFDE-1523-785FEABCD123` が見えるか確認します。
5. 広告確認後は対象側のリセットを1回押し、通常起動に戻ることを確認します。
   ファームウェアの復旧が必要なら、従来どおりリセットを2回押してUSBシリアルDFUを使います。

OTAには搭載ブートローダーのBLE DFU対応と、有効なSoftDeviceが必要です。
最初の実機試験は広告の確認までです。BLE転送と実機の入れ替えは未検証です。
通常レイヤーの配列やUSBシリアルDFUの生成方法は従来どおりです。

参考 [Adafruit nRF52 Bootloader](https://github.com/adafruit/Adafruit_nRF52_Bootloader)
